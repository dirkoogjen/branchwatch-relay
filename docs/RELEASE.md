# Branchwatch Relay v0.1.0

Branchwatch Relay runs Claude Code tasks in separate Git worktrees. Its companion monitor shows runner health, queues and task status in a browser. The monitor listens on the local machine in read-only mode by default. Unattended execution and queue dispatch require explicit configuration. The package includes Dutch and English setup instructions for macOS, Ubuntu and Windows, with test results in [Verification](VERIFICATION.md).

Branchwatch Relay voert Claude Code-taken uit in aparte Git-worktrees. De bijbehorende monitor toont de status van de runners, wachtrijen en taken in de browser. Standaard is de monitor alleen lokaal bereikbaar en alleen-lezen. Uitvoering zonder toezicht en verdeling van opdrachten vereisen aparte instellingen. Het pakket bevat Nederlandse en Engelse installatie-instructies voor macOS, Ubuntu en Windows. De resultaten staan in [Verificatie](VERIFICATION.md).
