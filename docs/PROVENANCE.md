# Source and rights / Bron en rechten

This release traces all 106 Python, JavaScript, CSS and HTML files to the project's own source snapshots. It contains 62 Runner 2 files, 32 files from Monitor 2 and 12 files from related monitor modules in the project's monitor repository. Some files were adapted for a separate installation. The other project files are release documentation, examples and a Git ignore file.

The source history includes Studio OBF, recovery and Codex author labels. Review of the available history, tracked license and notice files, in-file notices, external asset references and package contents found no identifiable bundled third-party code or media requiring separate attribution. The archive excludes production art, logos, external binaries and Git history. This is a source review based on the records available. Commit author labels do not independently establish legal ownership.

The project’s own material is dedicated to the public domain under CC0 1.0. The [license scope](../LICENSE-SCOPE.md) identifies the covered material. The text of the legal tool is supplied by Creative Commons. Claude Code, Python, Git and OpenSSH are separate prerequisites obtained under their own terms. Feedback is voluntary and independent of the dedication.
