# Branchwatch Relay

Branchwatch Relay coordinates Claude Code tasks in separate Git worktrees. The companion monitor shows runner health, queues and task status in a browser.

Branchwatch Relay verdeelt Claude Code-opdrachten over aparte Git-worktrees. De bijbehorende monitor toont de status van runners, wachtrijen en taken in de browser.

- [Nederlandse handleiding](docs/HANDLEIDING.md)
- [English user guide](docs/USER-GUIDE-EN.md)
- [Installatie / Installation for macOS, Ubuntu/Linux and Windows](docs/INSTALLATION.md)
- [Functies en architectuur / Functions and architecture](docs/ARCHITECTURE.md)
- [Beveiliging / Security](SECURITY.md)
- [Testresultaten / Test results](docs/VERIFICATION.md)

The monitor defaults to local, read-only access. Claude task execution requires explicit enablement and uses Claude Code’s permission bypass. See the security guide before enabling it.
